# Third-Party Software Notices

Zatom includes third-party software. Each third-party package remains subject
to its own copyright notices and license terms; Zatom's AGPL license does not
replace those terms.

The complete distributable notice bundle is available at
[`public/legal/THIRD_PARTY_NOTICES.txt`](public/legal/THIRD_PARTY_NOTICES.txt).

Contributors must run `npm run legal:generate` whenever production dependencies
change and commit the updated bundle.
